# Contributing

This is a research prototype with synthetic tools. The most useful contribution is a request the gateway should stop but might not.

1. **Write what you expect first**: should the call run, be held for a person, or be refused?
2. **Use made-up tools and data only.** No real credentials, endpoints or employer information.
3. **Open an issue** with the *Propose a test case* form, or a pull request with the case added to `tests/`.

Before a pull request: `npm ci && npm test`. Say what you expect the change to do to the policy outcome.

Security problems: see [SECURITY.md](SECURITY.md). Code is MIT.
