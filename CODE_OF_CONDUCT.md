# Code of conduct

This gateway is a research prototype; its value comes from people pointing out where it is weak. That only works if it is safe to do so.

**Expected**
- Criticise the test, the code or the claim, not the person.
- Bring evidence: a case, a file, a hash, a run.
- Say what you are unsure about. "I might be wrong" is welcome here.
- Use made-up data only. No real people, credentials, companies or employer information.

**Not accepted**
- Harassment, insults, or personal attacks, in public or private.
- Posting anyone's private information.
- Sexual language or imagery, or discrimination of any kind.

**If something goes wrong**
Report it privately to the maintainer, Roshan Trivedi, through the contact on [roshantrivedi.co.in](https://roshantrivedi.co.in/about/). Reports are kept confidential. The maintainer may edit or remove comments, close threads, or block accounts that break these rules.

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
